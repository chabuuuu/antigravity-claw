Agent Client Protocol (ACP) Server (agy acp)

              
Start the Antigravity Agent Client Protocol stdio server to connect IDEs (VS Code, JetBrains, Zed, Neovim) directly to this VPS.

              

                # Launch ACP stdio server directly or via SSH tunnel:

                agy acp --dangerously-skip-permissions
              

              

                In your local IDE ACP settings (e.g. Zed / VS Code Claude Code or ACP extension), set command to ssh -i ~/.ssh/id_rsa user@vps_ip "agy acp".
